# The table card ui design.

Guideline for Making a better Table ui card.

Current Table Card is messy and has no visual hierarchy.

Here are the Guidelines you need to follow to make better table ui.

1. Highlight the table header with suble color, not too dark but subtle that it can be recognized and read easily.
2. lighten the border shade between the rows, so it's easier to scan the data.
3. In Dates abbreviate the Month names.
4. Bold the important Record names
5. Highlight the selected row, and should have cursor pointer.
6. Hover state should be subtle, The micro-interaction is very much crucial here.
